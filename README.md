# Northwind PostgreSQL

## Objetivo

Projeto desenvolvido para estudos de banco de dados relacional utilizando PostgreSQL.

## Tecnologias

- PostgreSQL
- SQL

## Atividades realizadas

- Criação da estrutura do banco de dados
- Modelagem de tabelas
- Relacionamentos entre entidades
- Inserção e manipulação de dados

## Aprendizados

Durante este projeto pratiquei conceitos de modelagem relacional, consultas SQL e organização de dados em ambiente PostgreSQL.
